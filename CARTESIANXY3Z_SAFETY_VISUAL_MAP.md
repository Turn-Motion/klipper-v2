## Key Variables Reference

| Variable | Meaning | Range | Purpose |
|----------|---------|-------|---------|
| `x, y` | XY position | [0, p_x], [0, p_y] | Printer coordinates |
| `z, a, b` | Z/A/B axis positions | [min, max] | Bed/joint positions |
| `z_mz` | Z minus mean(A,B) | [-d_y, d_y] | Z-plane offset |
| `z_ab` | B minus A | [-d_x, d_x] | A-B tilt |
| `csx` | Cosine X-angle | [0, d_x] | Mechanical projection |
| `p_x, p_y` | Printing area | Config values | Work envelope |
| `d_x, d_y` | Joint spacing | Config values | Mechanical specs |
| `P_Z, P_A, P_B` | Joint positions | 3D coordinates | Support points |
| `P_E` | Extruder position | 3D coordinates | Nozzle location |
| `z_norm` | Bed normal vector | Unit vector | Bed orientation |
| `dist` | Extruder-bed distance | [-?, +?] | Signed clearance |
